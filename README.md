# Python String Analyzer 🐍

## About the Project
This beginner-friendly project demonstrates string handling in Python by performing basic text operations on a sentence.

## Concepts Covered
- `upper()` – Convert text to uppercase
- `lower()` – Convert text to lowercase
- `len()` – Count characters
- `split()` – Split a sentence into words
- `in` – Check whether a word exists
- `capitalize()` and `title()` – Format text

## How to Run
1. Download or clone this repository.
2. Open the project folder in your code editor.
3. Run the following command:

```bash
python string_analyzer.py
```
